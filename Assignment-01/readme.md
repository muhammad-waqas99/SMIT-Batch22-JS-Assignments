## Overview

This repository contains my solutions for JavaScript Assignment 01, focused on fundamental JavaScript concepts and basic problem-solving.

The assignment consists of 12 questions based on the concepts covered in the first nine chapters of *A Smarter Way to Learn JavaScript*.

## Topics Covered

- JavaScript Fundamentals
- Data Types
- `typeof` Operator
- Variable Naming Rules
- Arithmetic Operators
- Operator Precedence
- String Concatenation
- User Input using `prompt()`
- Output using `console.log()`
- Basic Mathematical Calculations
- Percentage and Discount Calculations
- Currency Conversion
- Salary Calculations

## How to Run

1. Clone this repository.
2. Open the `Assignment-01` folder.
3. Open `index.html` in your browser.
4. To run a specific question, make sure its JavaScript file is linked in `index.html`.
5. Open the browser console to view the output.
